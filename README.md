# Compass for Homebrew

The Homebrew tap of [Compass](https://compassbrowser.org), an open-source
Arc alternative built on Chromium ([source](https://github.com/Compass-Browser/Compass)).

```sh
brew install --cask compass-browser/tap/compass
```

or

```sh
brew tap compass-browser/tap
brew install --cask compass
```

Compass needs macOS 13 Ventura or later and runs natively on Apple silicon
and Intel Macs.

## Updates

Compass updates itself (Sparkle), so the cask is `auto_updates true`:
`brew upgrade` leaves it to the app unless you pass `--greedy`. The cask
follows the newest release, the canary channel, and Compass's release
tooling commits it after every macOS release (`Casks/compass.rb` is
generated by `tools/compass_tool/package_managers.py` in the Compass
repository: change it there).

## Uninstalling

```sh
brew uninstall --cask compass        # the app
brew uninstall --cask --zap compass  # the app, your profile and its caches
```

`--zap` deletes your Compass profile (`~/Library/Application Support/Compass`):
bookmarks, history, passwords and spaces that aren't synced elsewhere are gone.
